# Pokémon AI Adventure

This project is a Pokémon-style RPG where you can explore a world and interact with its inhabitants. The NPCs are powered by the Gemini API, which allows them to have dynamic conversations with the player.

## How to Launch

**Prerequisites:** Node.js

1.  Install dependencies:
    `npm install`
2.  Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key
3.  Run the app:
    `npm run dev`

## Code Structure

*   `App.tsx`: The main application component. It contains the game logic, including player movement, NPC interaction, and the chat interface.
*   `components/`: A folder containing reusable React components, such as icons.
*   `constants.ts`: A file containing constants used throughout the application, such as the grid size and NPC data.
*   `services/geminiService.ts`: A file containing functions for interacting with the Gemini API.
*   `types.ts`: A file containing TypeScript type definitions for the application.

## How It Works

The game is built with React and Vite. The player can move around a grid-based map and interact with NPCs. When the player starts a conversation with an NPC, a chat session is created with the Gemini API. The player's messages are sent to the API, and the NPC's responses are generated by the model.
